# Product direction

The user requires all interface work on this app to feel as if designed by Apple. Keep one coherent Apple-inspired design language: compact spacing, clear typography, restrained glass materials, rounded system-like controls, green switches, and accessible keyboard focus. Preserve the Uzbek default and Uzbek/Russian interface switching. Review visual changes in the running app before reporting them verified.

Do not use or take control of the user desktop for tests. Use isolated or headless checks only, unless the user explicitly permits desktop interaction.
